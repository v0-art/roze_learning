# М01 — комплект учебных промптов (редакция 1.0)

**Содержание модуля М01 утверждено:** 8 тем.  
**Сетка из 52 уроков пока ПРОЕКТНАЯ:** количество и отдельные промпты необходимо утвердить наставнику.  
**Формат идентификаторов:** `Модуль → Тема → Урок`, латинская кодовая запись `M01-T01-U01`, уникальная в базе данных. В текстах используется визуально совпадающий латинский `M`, а не кириллическая `М`: для технических ключей всегда берите значения из `manifest.json`.

## Состав

- `lessons/` — **52 самостоятельных, полноценных промпта**, по одному на урок. Встроены правила ведения занятий, входная проверка, уникальная проблема, содержательные фрагменты, 8 диагностических вопросов, все официальные ДЗ, заключительный отчёт.
- `topics/` — **8 объединённых Markdown-файлов** (по одному на тему) для удобной редакторской проверки.
- `assessment/M01-KR01.md` — первая тематическая контрольная после М01-Т05.
- `assessment/M01-KR02.md` — вторая тематическая контрольная после М01-Т08.
- `assessment/M01-EX01_24_open_tickets.md` — **публичный** банк 24 экзаменационных билетов: 48 разных теоретических вопросов + 24 разные практические задачи.
- `assessment/M01-EX01_24_open_tickets.json` — структурированный вариант билетов.
- `manifest.json` — оглавление, счётчики, SHA-256 каждого промпта.
- `platform_content_import_DRAFT.json` — **проект JSON-импорта** для разработчика NEXUS Academy, включая все тексты промптов, темы, навыки и связи.
- `lesson_report_schema_1.0.json` — проект JSON Schema для импорта результатов, совместимый по полям с предложенным ранее ТЗ площадки.

## Правильный процесс для обучающегося

1. Сайт выдаёт опубликованный промпт выбранного урока и, если есть, блок результатов предыдущего урока.
2. Ученик копирует единый промпт и проходит занятие в новом чате ChatGPT.
3. ИИ проводит обязательные этапы без подсказок при контроле, дозирует теорию строго по отдельной команде «Дальше».
4. Только после завершения теории и команды «я не умру чмом» проводится итоговый тест.
5. Преподаватель разбирает ответы, назначает все официальные ДЗ и выдаёт отдельный JSON-отчёт по `schemaVersion=1.0`.
6. Ученик вручную переносит JSON на сайт; сайт валидирует структуру, сохраняет попытку, навыки и пробелы, автоматически включает точные инструкции в следующий промпт.
7. Достоверность внешнего отчёта не подтверждается автоматически — наставник видит статус самоотчёта.

## Условия для разработчика площадки

- **Нельзя считать импортный JSON автоматически подтверждённой оценкой.**
- Не используйте `localStorage` как единственную базу.
- В `platform_content_import_DRAFT.json` все уроки имеют `status=draft`. Не открывайте их ученику без публикации наставником.
- Распознавайте идентификаторы только в латинском машинном формате `M01-T01-U01`. Русские подписи отображаются отдельно.
- Сохраняйте версию опубликованного промпта в снимке каждой попытки.
- Поля JSON-отчёта по текущему ТЗ — предложенный **контракт 1.0**, но API проекта в Google AI Studio ещё не подтверждено. Согласуйте и проверьте импортный адаптер с реально созданным приложением перед массовой загрузкой.
- В оценивании повседневных уроков используются 8 вопросов × 0/1/2 балла (макс. 16) для диагностики, а не официальная шкала экзамена. В контрольных и экзамене действует 50/70/80.
- В банке экзамена нет заранее утверждённых весов двух теоретических вопросов и практического задания: их задаёт наставник.
- После последнего урока предусмотрена заключительная проверка остатков ДЗ и проблемных зон перед зачётными мероприятиями; не создавайте фиктивный M01-T08-U07.

## Важные ограничения

Тексты представляют собой **промпты преподавателю**, то есть сценарии генерации полноценных объяснений и проведения проверок. Они не являются заранее написанными учебниками и не гарантируют правильность произвольного вывода внешней модели. Число часов — ориентир, глубина обучения определяется усвоением. Первые уроки М01-Т01 и М01-Т02 сохраняют ранее обсуждённые структуры с расширенными фрагментами.

Точный официальный файл регламента 2.1 в рамках данной сборки отсутствовал: правила восстановлены по зафиксированным и согласованным положениям беседы. Для строгой юридической/редакционной сверки потребуется актуальный оригинал регламента. Межпредметные ссылки на неразработанные уроки последующих дисциплин намеренно не детализированы.
