# Учебный сценарий

1. Ментор утверждает и публикует конкретные версии U01 и U02. Данные в репозитории — черновики; наличие файла не означает утверждения.
2. U01: сборщик включает официальный `promptTemplate`, опциональные реально сохранённые `generalRules` и `moduleInstructions`, не создаёт предыдущий отчёт. В исходном тексте U01 заданы проблемная задача, семь фрагментов, «Дальше», отдельная команда итоговой аттестации, восемь вопросов 0/1/2 и четыре ДЗ. Финальное уточнение не подставляет чужие баллы. Общий регламент/инструкции дисциплины в полях конкретной базы сейчас отсутствуют; их отдельная согласованная загрузка остаётся задачей.
3. При копировании или скачивании фронтенд отправляет текст на `/api/snapshots`; сервер сохраняет ID, пользователя, урок, текст и версию урока. Сервер повторно собирает промпт по актуальным данным и проверяет совпадение текста; фактический внешний диалог сайт не наблюдает.
4. Ученик загружает JSON. Проверяются урок, восемь ID Q01–Q08, 16 максимальных баллов, сумма результатов 0/1/2, обязательные перепроверки, четыре ID ДЗ U01. Сервер создаёт попытку, назначенные ДЗ и неустранённые пробелы. Повтор идентичного отчёта определяется по хешу.
5. Сборщик U02 использует данные предыдущей попытки: изученные темы, сильные стороны как предварительные, поимённые ошибки/частичные ответы, открытые пробелы, полные тексты незавершённых ДЗ, дополнительные проверки и комментарий ментора при наличии. Сначала ДЗ, затем ошибки и другие знания; без подсказок. После входного контроля преподаватель разбирает ответы и переходит к теме.
6. Отчёт U02 v1.1 может содержать результаты ДЗ по их ID и повторных проверок по ID вопроса. Сервер фиксирует историю ДЗ, меняет только переданные результаты и предварительно закрывает лишь конкретные проверенные пробелы. Отсутствие результата не приравнивается к выполнению. Для U02 требуются три ID назначенных им ДЗ.
7. Старые отчёты v1.0 принимаются без блока `entryControl`; результаты ДЗ и повторных проверок из них не выдумываются.

Старые пробелы можно адресовать через sourceGapId и sourceLessonId; записи без устойчивого ID вопроса требуют осторожной проверки. Результаты и подтверждения от внешней модели являются самоотчётом ученика. Текст четырёх ДЗ по ID отдельно не сверяется с утверждённым источником. Сценарий UI проверен на тестовой базе в Chromium; выполнение реального диалога с ChatGPT не проверено.
