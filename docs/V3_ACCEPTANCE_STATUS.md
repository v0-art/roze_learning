# Приёмка Rozephyr Learning 3.0

Проверка 12.11.2026. Результаты относятся к изолированной PostgreSQL с синтетическими учётными записями. «ПРОВЕРЕНО» означает перечисленный сценарий, а не эксплуатационную сертификацию. Названия критериев сокращены; точные формулировки — в [ТЗ 3.0](../contracts/rozephyr-v1/docs/02_TECHNICAL_SPEC_V3.md). Старые курсы владелец разрешил не переносить. M01 — тестовая реконструкция, не утверждённая программа.

Последующее решение владельца изменяет AT-12: подготовленный пакет целого модуля, темы или занятия проверяется и публикуется целиком. Пакет с пометкой тестовых критериев аттестаций отклоняется без сохранения; требуется исправленный архив. Настройка контрольных и учебного плана через специальные формы из интерфейса убрана. Первоначальный тест отдельной публикации относится к старому режиму репозитория.
