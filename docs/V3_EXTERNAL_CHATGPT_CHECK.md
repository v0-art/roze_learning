# Проверка архива занятия в ChatGPT

Автоматические тесты платформы уже проверяют выдачу ZIP и приём отчётов на синтетических данных. Они не доказывают, что конкретная версия ChatGPT сможет открыть этот ZIP и сформировать результат.

Для ручного испытания подготовлен [тестовый архив занятия](../artifacts/v3-acceptance/session-package-v2.zip). Он содержит предоставленный тестовый материал M01-T01-U01, регламент и схему отчёта. Ученик и сессия тестовые; реальных персональных данных в архиве нет. Если вы уже начали проверку с предыдущим файлом `session-package.zip`, продолжайте с ним: отчёт должен соответствовать именно тому архиву, который вы открыли.

1. Откройте новый диалог ChatGPT с возможностью работы с файлами.
2. Прикрепите только ZIP занятия и отправьте его без дополнительного промпта: инструкции должны сработать из самого архива. Зафиксируйте, открыл ли ChatGPT архив и прочитал ли `START_HERE.md` без подсказки. Если без подсказки он не продолжил, отметьте это как результат испытания; дополнительная подсказка может использоваться лишь как отдельный диагностический эксперимент.
3. Пройдите занятие до конца. Сохраните отчёт, который вернёт ChatGPT: ZIP с `report.json` или сам `report.json`.
4. Сообщите, удалось ли ChatGPT прочитать архив и какой файл он вернул. Структуру результата и его привязку к архиву можно проверить командой:

   ```bash
   npm run test:v3:external -- artifacts/v3-acceptance/session-package-v2.zip путь/к/отчёту.json
   ```

Проверка не оценивает правильность учебного содержания. Сессия создана в удалённой после испытания временной базе, поэтому этот конкретный отчёт **нельзя импортировать в рабочий сайт**: для настоящего прохождения нужно скачать новый архив из своего кабинета.
