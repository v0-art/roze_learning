# Видимая локальная демонстрация трёх уроков

## Как открыть

1. Откройте **http://127.0.0.1:3100/** и нажмите «Войти».
2. Логин ученика — `demo`. Пароль находится локально в файле `.env.visible-demo` проекта, в строке `NEXUS_DEMO_PASSWORD`. Скопируйте только значение после знака `=` и введите код с картинки. Пароль в этот документ не выводится.
3. Для переключения состояний выйдите из учётной записи, войдите как `mentor` с паролем из строки `NEXUS_MENTOR_PASSWORD` того же файла, откройте обзор и в блоке «ДЕМО · СИНТЕТИЧЕСКИЕ ДАННЫЕ» выберите 0, 1, 2 или 3 урока. Войдите снова как `demo` или обновите уже открытую страницу ученика в другом браузере. Ученику управление состояниями недоступно.
4. В панели ментора откройте «Ученики» → «Результаты» у демонстрационного ученика. В состоянии 3 на обзорной панели доступна кнопка предпросмотра следующего урока: он остаётся черновиком и ученику не доступен.

Если демонстрационный сервер остановлен, в каталоге проекта выполните `npm run demo:visible`. Требуются установленные Node.js и зависимости проекта. Запуск использует `127.0.0.1:3100`, отдельный файл данных `data/visible-demo/database.json` и отдельные пароли, не использует рабочую базу. Пароли и база исключены из Git; доступ к ним определяется правами Windows и каталога проекта. Не отправляйте файл с паролями и не открывайте сервер в сеть.

## Что проверено

| Состояние | Результат | ДЗ | Открытые пробелы |
|---|---|---|---|
| 0 | Нет попыток | Нет | 0 |
| 1 | 12/16 | 4 назначены | 3 |
| 2 | 12/16 + 11/16 | 3 проверены по самоотчёту, 1 на доработке; 3 новых назначены | 5 |
| 3 | 12/16 + 11/16 + 12/16 = 35/48 | 7 проверены по самоотчёту, 3 новых назначены | 4 |

Сумма баллов является суммой диагностических результатов, а не оценкой экзамена или подтверждением ментора. Проверка ДЗ помечена как проверка ИИ по самоотчёту, не как решение ментора. `M01-T01-U01:Q05` предварительно устранён только после третьего урока, `M01-T01-U02:Q06` остаётся открытым. Вопросы с одинаковым номером из разных уроков различаются. Ученик видит три опубликованных урока в отдельной демо-базе, четвёртый не опубликован. Три пройденных урока не означают завершение модуля или всей программы.

Три предоставленных JSON импортированы без изменений через ученический интерфейс. Четыре состояния сохранены на диске и проверены переключением через интерфейс ментора. После рестарта отдельного сервера выполнен повторный вход через UI и проверены три сохранённые попытки; для автоматического входа использовалась тестовая капча. Оставленный сервер использует обычную капчу. Попытки, ДЗ, пробелы и снимки промптов принадлежат только демо-ученику; переключение затрагивает только его записи в изолированной базе. В обычном серверном режиме демо-API не зарегистрирован.

Исправлено повторное создание старых пробелов как ошибок нового урока. Также исправлена подпись на дашборде: правильные ответы в самоотчётах больше не объявляются подтверждёнными навыками. Блок после прохождения всех опубликованных уроков не утверждает, что вся программа завершена.

Проверки: `npm test` — 39 тестов успешно; `npm run lint` и `npm run build` — успешно. Через браузер проверены три импорта, карта, переключатель, профиль ученика у ментора и предпросмотр четвёртого урока. Повторный импорт, некорректный JSON и изоляция пользователей проверены интеграционным тестом трёх уроков. Сборка предупреждает о размере основного JS-файла.

## Ограничения

Не были приложены `manifest.json`, `03_expected_states/` и `04_expected_carryover/`; проверка проведена по явным значениям задания и трём JSON. Сравнение с отсутствующими эталонами невозможно. Данные синтетические: обращения к ChatGPT/Gemini не выполнялись, результаты не являются реальным обучением. Демо-сервер предназначен только для локального просмотра; для внешнего размещения необходима отдельная подготовка и проверка безопасности.
