# Состояние реализации

**Частично готов.** Локально запускается; типы, сборка и тесты проходят. Не объявлять промышленную готовность.

- Хранение: `data/nexus_academy.json`; Node/Express, React/Vite; ментор из окружения и ученики с хешированными паролями. Локальные секреты задаются через `.env`.
- Учебные материалы: в текущей базе 18 модулей, восемь тем M01 и 52 черновых урока. U01 и U02 существуют в базе. Публикация — решение ментора, программно не произведена в реальных данных.
- U01/U02: сохранение снимка, проверка отчёта, учёт ДЗ и перенос в следующий урок реализованы; HTTP-интеграция проверяется на изолированной базе.
- ДЗ: проверено ИИ означает запись результата, перенесённого учеником; дополнительная проверка ментором — исключительная операция.
- Аттестация: серверные самоотчёты для опубликованных контрольных/экзаменов, пересдачи и решение ментора о дополнительной попытке. Форма пока использует фиксированные максимумы 30/30/40, а не индивидуальные критерии каждой работы. После второй неудачной пересдачи создаётся предупреждение; отдельного назначения даты нет.
- Карта: модули → темы, реальные связи из учебных данных, навигация/zoom; по прямому запросу пользователя навыки не представлены как отдельный уровень карты. Карта, wheel и мобильная ширина проверены в Chromium.
- Для запуска вне локальной машины необходимо решить задачи безопасности, TLS, изоляции учётных записей, автоматических бэкапов, миграций, устойчивого хранения сессий и управления менторами и нагрузочных/браузерных тестов.

Степень соответствия и доказательства: [COMPLIANCE_AUDIT.md](COMPLIANCE_AUDIT.md).
