Проверено:

- Каждый пакет создаёт только объявленную в его манифесте сущность. После последовательной загрузки сохранены ровно три сущности и три редакции.
- Загрузка темы до модуля отклоняется, база остаётся без частично созданных сущностей.
- Урок связан с модулем и темой; сохранены 13 Markdown-блоков, включая семь блоков теории. Тексты сопоставлены с исходным архивом.
- Повторный импорт каждого пакета возвращает `unchanged`, не создаёт новых редакций и не публикует материалы.
- Экспорт полученного набора с повторным импортом не меняет данные.
- Те же три пакета поочерёдно загружены и повторно проверены через интерфейс ментора.

Команды для PostgreSQL и браузера:

```bash
npm run test:v3
node --import tsx --test tests/relational-v3-m01-browser.e2e.ts
```

Тестовая PostgreSQL должна быть доступна; при нестандартном порте используется `NEXUS_TEST_POSTGRES_PORT`. Браузерный тест требует установленного Chromium для Playwright.

**Граница проверки:** исходный комплект содержит только модуль, тему и занятие. Он не содержит учебный план и регламент, которые необходимы для выдачи персонального архива занятия ученику. Текст занятия является новой тестовой редакцией из комплекта, а не подтверждённой копией отсутствующего оригинала. Материалы не публиковались и не импортировались в действующую базу сайта.
