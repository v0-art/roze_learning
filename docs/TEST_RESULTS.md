# Результаты проверки

Дата: 2026-11-02; локальный Node.js 24.22.2 и установленные зависимости.

| Команда | Результат |
|---|---|
| `npm run lint` | Успешно: `tsc --noEmit` (отдельного ESLint в проекте нет). |
| `npm run build` | Успешно: сборка Vite. |
| `npm test` | 32 теста успешно, 0 неуспешных; включает HTTP-интеграцию с отдельным файлом базы и временным сервером. |

Интеграция проверяет: запрет анонимного доступа и поддельного `constructor`-логина; ограничения ученика; публикацию на тестовой базе; U01 со снимком и демонстрационным отчётом 12/16; отказ при неправильной сумме; идемпотентный импорт; четыре назначенных ДЗ и три пробела; реальную сборку U02 с условиями и Q02/Q05/Q06; отчёт 1.1, предварительное устранение Q02 и сохранение Q05/Q06, историю одного ДЗ; проверку ментора; неопубликованный экзамен, попытки, уведомления, лимит и дополнительную попытку; защиту от устаревшей записи CMS.

Это HTTP-интеграционный тест, не тест реального ChatGPT. Нагрузка и независимый аудит безопасности не выполнялись. Исходная отдельная JSON Schema и корректный ZIP полного комплекта недоступны; полную сверку контракта/импорта провести нельзя.


`npm run test:e2e`: 1 браузерный сценарий Chromium успешно на отдельной базе. Проверены создание ученика, публикация/снятие публикации, копирование промпта, отправка U01 и U02, статусы ДЗ и пробелов, карта на десктопной и мобильной ширине, колесо и возврат. Настоящий внешний диалог с ИИ не проводился. Тестируются два ученика, отдельная контрольная и восстановление резервной копии.

Во время отладки браузерный тест выявил отсутствие обновления кнопки после публикации — синхронизация CMS исправлена. Один параллельный прогон сборки и тестов не дождался запуска тестового сервера за 8 секунд; ожидание увеличено, последовательный повтор успешен.

Дополнительно проверены раздельные меню ролей, выход ментора, отзыв прежней сессии и последующий вход ученика в том же браузере. Сессии хранятся в памяти сервера и заканчиваются при его перезапуске.
