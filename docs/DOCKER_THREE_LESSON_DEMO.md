# Демонстрация трёх занятий в Docker

На локальном сайте `http://127.0.0.1:18080` создан отдельный курс «ДЕМО · три занятия (синтетические данные)» и отдельный демонстрационный ученик. Учётные данные ученика записаны в `data/docker-demo-credentials.txt`; файл исключён из Git. У ментора этот курс можно выбрать в списке курсов, затем открыть разделы «Отчёты» и «ДЗ» для демонстрационного ученика.

Три существующих демонстрационных отчёта из `tests/fixtures/visible-demo/` последовательно отправлены в работающий API Docker-сайта. Перед каждым отчётом API сформировал и сохранил снимок промпта. Перед импортом U02 проверено наличие первого ДЗ U01 в его промпте. Результаты записаны в отдельную копию PostgreSQL в Docker, а не в исходную базу.

| Занятие | Результат отчёта |
|---|---:|
| M01-T01-U01 | 12 / 16 |
| M01-T01-U02 | 11 / 16 |
| M01-T02-U01 | 12 / 16 |

После трёх отчётов сохранены 10 заданий и 4 открытых пробела. У ученика отчёты доступны в разделе «Прогресс», задания — в разделе «ДЗ». Результаты не подтверждены ментором.

Проверка браузером: в прогрессе видны все три отчёта; карта содержит 18 модулей; при переходе с карты на дашборд её ширина не изменялась. Для браузерной проверки использована короткая тестовая сессия; прохождение CAPTCHA автоматически не проверялось.

Отчёты и результаты синтетические: реальное занятие с ChatGPT не проводилось. Эта версия не содержит прежнего переключателя состояний 0–3; показано итоговое состояние после третьего занятия.
