# Проверка сценария трёх уроков

Дата проверки: 2026-11-03. Для испытания запущен отдельный сервер с временной копией файла данных, создан отдельный ученик и опубликованы только три тестируемых урока. Рабочие аккаунты, результаты и решения о публикации не изменялись. Тестовые отчёты находятся в `tests/fixtures/three-lesson/`.

Исходные три JSON помечены авторами как симуляция. Настоящий сервер обоснованно отклоняет такие отчёты; каждый из оригиналов проверен на этот отказ. Для дальнейшего технического теста в оперативной копии меняется только поле `studentNotes`, остальные результаты и исходные файлы не меняются. Это проверка обработки синтетических данных, не реальное обучение и не проверка поведения ChatGPT. Внешний ИИ не вызывался.

## Обнаруженные ошибки и исправления

- Валидатор отклонял `resolved_preliminary` и полные идентификаторы вроде `M01-T01-U01:Q05`. Теперь они принимаются с проверкой соответствия исходному уроку; статус сохраняется как предварительный.
- При сборке промпта вопросы разных уроков с одним номером смешивались, а полные инструкции по проверке ДЗ не переносились. Идентификация теперь учитывает урок и номер вопроса, инструкции сохраняются.
- Сервер не принимал проверку невыполненного ДЗ более раннего урока. Теперь он принимает принадлежащее ученику открытое задание, включённое в снимок промпта; история проверок сохраняет фактический исходный урок и свидетельство.
- У валидатора терялись текст вопроса, ответ и баллы по отдельным вопросам, а также свидетельство проверки ДЗ. Эти поля сохраняются, если присутствуют.
- Старые тесты зависели от текущих публикаций в рабочем файле. Тесты, которым нужны черновики, теперь подготавливают собственную копию; рабочие статусы не сбрасываются.

## Результаты команд

- `npm run lint` — успешно (в проекте это проверка TypeScript `tsc --noEmit`).
- `npm run build` — успешно; Vite предупреждает о размере основного JS-файла более 500 КБ.
- `npm test` — 39 тестов пройдены; включает unit и серверные интеграционные тесты.
- `npm run test:e2e` — браузерный тест пройден в локальном Chromium.
- Для сервера и тестов использовался установленный Node.js; сетевые взаимодействия ограничивались локальным временным сервером.
