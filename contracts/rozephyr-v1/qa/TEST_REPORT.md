# QA отчёт по пакету Rozephyr 3.0

Проверены: синтаксис всех JSON Schema Draft 2020-12, положительные примеры content/session/result, корректное открытие 3 архивов примеров, рендер 4 DOCX в 17 страниц PDF. Все положительные примеры проходят локальную структурную проверку.

**Что не проверено:** реальное приложение PostgreSQL и действия на интерфейсе; совместимость ZIP с конкретным пользовательским режимом ChatGPT; историческая миграция БД. Комплект — требования и проект контрактов для внедрения Codex, не выполненная работа над сайтом.

UI-FREEZE-001: весь визуальный интерфейс должен сохраниться. UI-EXCEPTION-001: единственное разрешённое изменение — «Копировать JSON» → «Скачать архив» для выдачи персонального ZIP занятия.
