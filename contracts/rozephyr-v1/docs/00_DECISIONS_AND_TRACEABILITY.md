## Уточнения C01–C07

**C01.** По идентификатору сравнивать актуальный материал с загруженным. Если содержимое одинаково — не менять вообще. Если отличается — сохранить старую версию и создать новую с увеличенным номером. Для ранее неверсионированного содержимого исходную редакцию считать v1; изменённую — v2. Новая версия черновая до отдельной публикации. Текущая опубликованная версия продолжает обслуживать учеников до публикации новой.

**C02/C25.** Генератор и ментор отвечают за педагогический смысл. Сайт проверяет обязательные поля, типы, ограничения JSON Schema и элементарные технические свойства архива (читаемость и наличие упомянутых файлов), но **не интерпретирует смысл** текста, не проверяет методическую правильность, не устраивает экспертную оценку графа знаний и не переформулирует материал. Ссылки на отсутствующие ресурсы нельзя успешно прочитать, поэтому их наличие допускается проверять как техническое условие чтения, а не как педагогическую проверку.

**C03/C29.** Реальных учеников на момент решения нет. Предусмотрено преобразование имеющихся материалов и тестовых данных с резервным архивом. Не переносить механически временные демо-аккаунты и синтетические попытки в рабочую учебную историю. После успешного преобразования старый формат больше не обязателен для штатного импорта.

**C04.** Исчерпание пересдач запрещает дальнейшие попытки конкретного контроля до решения ментора, но **не блокирует курс целиком**. Для контрольной возможен отдельно заданный ментором локальный барьер перехода; это не глобальная блокировка. Экзамену задаются отдельные условия завершения модуля.

**UI-EXCEPTION-001.** Уточнение владельца от 10.11.2026: вместо копирования JSON, которым выдаётся материал занятия, реализовать скачивание персонального архива. Единственное утверждённое изменение надписи — **«Скачать архив»**. Подмена функции копирования любых других JSON-объектов без подтверждения запрещена.

**C05.** В ZIP занятия должен быть `START_HERE.md` с однозначным порядком чтения файлов и командой начать занятие. Способность конкретного режима ChatGPT корректно прочитать ZIP требует практического испытания; в документации не выдаётся за подтверждённую.

**C06.** Основной артефакт ответа — ZIP с `report.json`. При невозможности создать архив внешний ИИ может вернуть корректный `report.json`, который платформа принимает тем же валидатором.

**C07.** Платформа доверяет корректно оформленному отчёту ученика. Добросовестность не проверяется независимо. Источник — `external_ai_user_submitted`; это не решение ментора.

## Жёсткая граница изменения пользовательского интерфейса

**UI-FREEZE-001:** Не менять интерфейс Rozephyr Learning: компоновку, стили, CSS/Tailwind-классы, цвета, типографику, значки, иллюстрации, расположение, анимации, навигацию, responsive-поведение и существующие действия остальных кнопок. **Единственное разрешённое исключение UI-EXCEPTION-001:** действие выдачи учебных данных «Копировать JSON» (либо эквивалентный контрол копирования содержимого занятия, который Codex идентифицирует в актуальном интерфейсе) заменяется на **«Скачать архив»**: те же положение, размер, классы, цвета, иконка — если смысл иконки не противоречит загрузке, — и визуальные состояния; новая функция скачивает персональный ZIP занятия. Не заменять на скачивание другие кнопки, включая несвязанные элементы копирования JSON отчёта. При неоднозначности названия элемента сначала определить фактический экран и показать владельцу точечный перечень привязок. Остальной интерфейс без изменений.
